# [HTTP] 요청·응답과 상태 코드

태그: HTTP · FastAPI │ 처음 배운 날: 2026-11-02 │ 쓰는 곳: fastapi-memo

## 한 줄 정의

HTTP는 클라이언트(브라우저)가 서버에 요청을 보내고, 서버가 응답과 상태 코드를 돌려주는 약속이다.

## 비유

식당 주문서. 손님이 "GET /hello 하나요"라고 주문서를 내면, 주방(서버)이 음식(JSON)과 영수증 도장(200 성공 / 404 그런 메뉴 없음)을 같이 내준다.

## 오늘 직접 본 것

| 요청 | 결과 | 이유 |
|---|---|---|
| `GET /` | 404 Not Found | `/` 메뉴는 안 만들었다 |
| `GET /favicon.ico` | 404 | 브라우저가 탭 아이콘을 자동으로 찾았는데 없었다 |
| `GET /hello` | 200 OK + `{"message":"안녕, Jay"}` | `@app.get("/hello")`로 만든 메뉴 |

## 코드

```python
@app.get("/hello")        # GET 방식으로 /hello에 요청이 오면
def hello():
    return {"message": "안녕, Jay"}   # 이 JSON을 응답으로 돌려준다
```

## 주소 읽는 법

`http://127.0.0.1:8000/hello` = 규칙(http) + 내 컴퓨터(127.0.0.1) + 창구 번호(8000) + 메뉴(/hello)

## 자주 쓰는 상태 코드 (내일 강의에서 더 채우기)

200 성공 · 201 만들기 성공 · 404 없음 · 422 보낸 데이터 형식이 틀림 · 500 서버 내부 에러

## 헷갈렸던 점

404가 떠서 서버가 고장 난 줄 알았는데 /에 아무것도 안만들어놓았기 때문에 없는 주소를 요청해서 404가 떴다. /hello로 바꾸니 정상작동했다.

## 면접 질문에 답해 보기

**Q.** 404와 500의 차이는?

**A.** 400번대는 요청이 잘못됨, 500번대는 서버가 잘못됨
